# 食光

校园食堂点评推荐。帮助学生在「今天吃什么」上少纠结：按时段给一道稳妥的菜，标出新品，并把近期差评集中的窗口单独放出来。

当前是第一版，使用模拟数据，可以直接打开。

## 页面

- **今天吃什么**：按当前时间区分早餐、午餐、下午、晚餐、夜宵，结合食堂、口味和预算给出推荐。
- **找菜**：搜索菜名、窗口或食堂，可筛新品、隐藏踩雷菜。
- **窗口口碑**：按档口而不是按菜名看评价，差评窗口放在前面。
- **我的收藏**：保存在本机浏览器。

菜品详情里能看到价格、排队时间、窗口备注和同学评价摘录。

## 本地查看

用浏览器直接打开 `index.html`，或在项目目录启动静态服务：

```bash
python -m http.server 4173
```

然后访问 http://127.0.0.1:4173/

## 数据

模拟数据在 `js/data.js`，分成食堂、窗口、菜品三层。页面逻辑在 `js/app.js`，不依赖构建工具。
